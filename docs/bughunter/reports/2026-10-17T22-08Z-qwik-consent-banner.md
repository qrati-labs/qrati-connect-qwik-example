- Scope: client-side consent initialization from Qwik app mount through geo decision, GTM initialization, consent-library startup, and footer preferences action.
- Base: `b67ada21e20324817ec1815907e6eb82ab5b4f0b` (`origin/main`).

Initialization uses one module-level promise to avoid duplicate `CookieConsent.run` calls and applies choice callbacks to Consent Mode (`:115-168`). This is not filed as a new finding in this report: the pattern is explicitly in consent-initialization PR #1, and the same workflow is already covered by open PR #3's worker-routing report only indirectly.
